CET SOFTWARE HUB
================

Open index.html directly in a browser. It is intentionally self-contained:
- HTML, CSS and JavaScript are all inside index.html.
- No server, domain, external CSS, JavaScript, fonts or images are required.
- Search, filtering, modal instructions and buttons work offline.
- Installation buttons open external official download pages, which require internet.

TO CUSTOMIZE
------------
Open index.html in VS Code/Notepad++ and edit the `apps` array near the bottom.
For each application you can change:
name, major, courses, icon, description, tags, url and installation steps.

TELEGRAM BOT
------------
Send index.html as a Telegram document. The student downloads it and opens it
locally in Chrome/Edge/Firefox. The bot does not need to host the page.
